# Assets: web → Android / iOS resources

Referenced by [`nextjs-to-native`](../../SKILL.md) in phase 1 (inventory) and phase 5 (import). Assets are images, illustrations, animations, sounds, fonts, icons, the app icon and the splash screen. Like tokens, they have **one source** (`shared/assets/`) and are **generated** into each platform's resource format. Never hand-copy files into `res/` or `.xcassets` one at a time.

## 1. Bundled vs remote: decide per asset

| Kind | Example | Where it comes from in the app |
|---|---|---|
| **Bundled** | logo, illustrations, empty states, backgrounds, onboarding art, medals, SFX, fonts, icons | `shared/assets/` → generated platform resources, shipped in the binary |
| **Remote** | product/course images, user avatars, CMS or CDN images, anything whose URL comes from the API | Loaded at runtime with a caching loader (Coil on Android; a caching loader such as Nuke or Kingfisher on iOS, see the stack files). **Not copied.** Note the host so the app's network config allows it |

Rule of thumb:
- If the web references it as a static path (`/images/...` in `public/`, an `import img from './x.png'`, or a `next/image` `src` that is a literal), it is bundled.
- If the path or URL comes from data, it is remote.
- If a static path is keyed by an ID (`/images/course/<uuid>.png`), ask whether it should move to the backend. Shipping content art in the binary means an app release for every new item.

## 2. Inventory (phase 1)

Find assets in:
- `public/**`
- `import`ed image, audio and font files
- `next/font` calls (`layout.tsx`)
- icon packages (`lucide-react`, `@heroicons/*`, `@hugeicons/*`, `@phosphor-icons/*`, …)
- CSS `url(...)`
- inline `<svg>` components
- Lottie JSON
- `new Audio(...)` and Web Audio code (SFX may be *synthesized*, with no files)
- brand or theme configs that point at logos

Then grep the source for each path. Assets that nothing references, or that only non-`nativize` screens or other brands reference, don't need importing. Assets that are referenced but **missing from the repo** are findings: ask for them.

Write `migration/ASSETS.md` (`templates/migration-progress.md`). Each row holds:
- asset and path
- size
- the `nativize` screens that use it (`file:line`)
- bundled or remote
- target format
- licence
- open questions

Flag oversized files. A 4 MB PNG or a 2 MB GIF that is fine on a CDN is not fine in an app binary.

**If the web is being redesigned**, inventory both, and plan the import from the version that will ship (see the phase 1 note on spec sources).

## 3. Formats per platform (phase 5)

| Source | Android | iOS |
|---|---|---|
| SVG icon / simple illustration | VectorDrawable XML in `res/drawable` (Android Studio's Vector Asset tool, or `vd-tool` / `svg2vector` in a script). Check unsupported SVG features: filters, masks, some gradients, embedded rasters | Asset catalog image set with the SVG (or a PDF), "Preserve Vector Data" on, single scale |
| Complex SVG (filters, textures) | Rasterize to WebP at densities | Rasterize to @2x / @3x |
| PNG / JPG raster | Lossy or lossless **WebP** at mdpi / hdpi / xhdpi / xxhdpi / xxxhdpi (`res/drawable-*dpi`), from the largest source, downscaled to the size actually displayed | Image set at @2x / @3x (PNG or HEIC). Size from the displayed point size, not the source |
| GIF / animation | Animated WebP (Coil decodes it), or re-author as Lottie (`lottie-compose`). Replace loading GIFs with native progress indicators | Lottie (`lottie-ios`), an animated image, or a native indicator |
| Lottie JSON | `lottie-compose`, file in `res/raw` | `lottie-ios`, file in the bundle |
| Audio (SFX) | `res/raw` + `SoundPool` (short) / Media3 (long). Synthesized web SFX: re-synthesize, or render once to short OGG/WAV files | Bundle + `AVAudioPlayer`. Same choice for synthesized SFX |
| Fonts | `res/font` (TTF/OTF), only the weights in use | Bundle the files and list them in `UIAppFonts`. Use `Font.custom(_:size:relativeTo:)` |
| Icon set (Lucide, Heroicons, Hugeicons, Phosphor) | Only glyphs in use → VectorDrawables, generated by a script from the package's SVGs | Same → asset catalog symbols (SVG) or custom SF Symbol templates |

Name resources the same way on both platforms (`ic_badge_gold` on Android, `icBadgeGold` or `ic_badge_gold` on iOS) and record the mapping in `ASSETS.md`, so lead-follow ports are mechanical.

## 4. App icon and splash screen

These have no web equivalent. A favicon is not an app icon. Ask for the source art early (phase 2).

- **App icon:** a 1024×1024 master plus a monochrome or symbol layer.
  - Android: an adaptive icon (foreground / background / **monochrome** layers, 108dp canvas with a 72dp safe zone) and a Play Store 512×512 icon.
  - iOS: a layered icon from Icon Composer (`.icon`, which supports the light, dark and tinted appearances), or a single 1024 PNG on older toolchains. Confirm the current requirements live.
- **Splash:**
  - Android: the SplashScreen API (an icon on a background color, Android 12+ behaviour backported by `core-splashscreen`).
  - iOS: a launch screen (storyboard or `UILaunchScreen` Info.plist keys).

  Brand color comes from the tokens. Never a full-screen image with text.

## 5. Pipeline

- `shared/assets/` holds the sources, organised by kind (`icons/`, `illustrations/`, `backgrounds/`, `audio/`, `fonts/`, `app-icon/`), plus a manifest (`assets.json` or the table in `ASSETS.md`) listing each asset's name, source and targets.
- A script (`shared/assets/generate.*`) converts and writes into `android/app/src/main/res/` and `ios/<App>/Resources/Assets.xcassets` (or a `DesignSystem` package's resources). Run it from CI to check that the generated output is up to date. Mark generated folders as generated in the guard hooks.
- Optimize on the way in: WebP or HEIC quality around 80–90 for illustrations, strip metadata, cap dimensions at the largest display size × 3.

## 6. Licences

Before an asset ships in a binary:
- **Fonts:** OFL and Apache allow embedding. Commercial fonts often need an app licence.
- **Icon sets:** check the licence (Lucide is ISC; Hugeicons free is MIT-like, but the Pro set isn't free).
- **Stock or AI-generated illustrations:** confirm ownership and terms.

Record the licence per row in `ASSETS.md`.

**Gate (phase 5):**
- Every bundled asset used by a `nativize` screen is generated on both platforms and shows on the gallery screen.
- The app icon and splash render on a device.
- Every asset has a licence entry.
- No source file over the agreed size budget ships unoptimized.
